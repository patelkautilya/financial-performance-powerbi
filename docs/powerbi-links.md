All are saved in the author's My workspace. The report has four pages with country slicers. The overview dashboard contains pinned monthly sales, segment profit and KPI visuals. The dedicated KPI dashboard contains a live tile of the six-metric scorecard page. Static pinned visuals and a live report page tile are different objects; the latter retains the page's country-filter interaction.

These links require authorized Power BI access. For public review on GitHub, use the repository's PDF and PNG previews or download the PBIX. Publishing files to GitHub does not grant access to the Power BI workspace. No anonymous Publish to web link or scheduled refresh has been configured.
